================================================================
            NeoCat 背景轮换系统 + 毛玻璃重构 使用说明
================================================================

一、前置条件
-------------
1. 你的项目必须是 Next.js + TypeScript + Tailwind CSS
2. 部署在 Cloudflare Workers（通过 OpenNext）
3. 需要一个 Cloudflare R2 存储桶（免费额度足够）
4. （可选）需要一个 Cloudflare KV Namespace 来持久化轮换设置

二、快速部署
-------------
1. 将 neocat-deploy.sh 上传到服务器项目根目录（~/homepage）
2. 执行：bash neocat-deploy.sh
3. 脚本会自动创建所有必需文件和目录
4. 编辑 .env.local 填入你的配置
5. 修改 app/layout.tsx 加入 BackgroundWrapper
6. 执行 npm run build 并部署

三、R2 配置步骤
-----------------
1. 登录 Cloudflare Dashboard → R2 → 创建存储桶
   - 名称：backgrounds（或自定义，需同步修改 .env.local 中的 R2_BUCKET_NAME）
2. 在 R2 页面 → 管理 → 创建 API 令牌
   - 权限：对象读写
   - 记录下 Account ID、Access Key ID、Secret Access Key
3. 将这些值填入 .env.local

四、KV 配置（可选）
-------------------
1. Cloudflare Dashboard → Workers & Pages → KV → 创建命名空间
   - 例如：BG_SETTINGS
2. 在 wrangler.toml 中添加绑定：
   [[kv_namespaces]]
   binding = "BACKGROUND_SETTINGS"
   id = "你的KV命名空间ID"
3. 如果不使用 KV，轮换设置将保存在内存中，Worker 重启后会重置为 daily

五、手动修改 layout.tsx
------------------------
打开 app/layout.tsx，做两处修改：

（1）在文件顶部添加导入：
import BackgroundWrapper from "@/components/BackgroundWrapper";

（2）将 <body> 标签内的内容用 <BackgroundWrapper> 包裹：
<body>
  <BackgroundWrapper>
    {children}
  </BackgroundWrapper>
</body>

六、管理后台使用
-----------------
1. 部署后访问 https://你的域名/admin/background
2. 输入你在 .env.local 中设置的 BACKGROUND_ADMIN_TOKENS
3. 点击“连接”
4. 上传一个 .zip 压缩包（内含 jpg/png/webp/gif/avif 图片）
5. 选择轮换模式：每天/7天/14天/30天/随机
6. 返回主页，背景自动生效

七、常见问题
-------------
Q: 上传 zip 后没有反应？
A: 检查 .env.local 中的 R2 配置是否正确，确保 Bucket 已创建且 API 令牌有写入权限。

Q: 背景不显示？
A: 打开浏览器控制台，查看 /api/background/current 的响应。如果返回 error，检查 R2 配置。

Q: 我不想用 R2，想用本地图片？
A: 可以将图片放在 public/backgrounds/ 目录下，然后修改 BackgroundWrapper.tsx，
   直接写死背景 URL 或使用简单的日期切换逻辑。

八、技术栈
----------
- Next.js 15 (App Router)
- Tailwind CSS 4
- Framer Motion (已集成)
- JSZip (解压 zip)
- Cloudflare R2 (对象存储)
- Cloudflare KV (可选，设置持久化)
